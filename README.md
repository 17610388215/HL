# All-in-One Online Tools

A scalable, privacy-focused collection of free online utilities for English-speaking users.

## Product direction

- Next.js App Router, React, TypeScript, and Tailwind CSS
- Browser-side PDF and image processing whenever practical
- Mobile-first, accessible, fast, and SEO-friendly
- Reusable architecture designed to grow to hundreds of tools
- No registration or paid APIs required for the first release

## Phase 1

The first release is planned around 20 functional tools across five categories:

- PDF: merge, split, rotate, and JPG to PDF
- Images: compress, resize, JPG to PNG, and PNG to JPG
- Calculators: percentage, loan, compound interest, and GPA
- Text: word counter, character counter, case converter, and text compare
- Converters: length, weight, temperature, and speed

Additional category foundations will cover developer, AI, video, and audio tools.
